# Contributing to IOE Entrance Model Question Paper Generator

First off, thank you for considering contributing to this project! It's people like you that make the open-source community such an amazing place to learn, inspire, and create.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue and include:
* A clear and descriptive title
* Steps to reproduce the bug
* Expected behavior vs. what actually happened
* Any relevant logs or screenshots

### Suggesting Enhancements
Have an idea to make the tool better? We'd love to hear it! Open an issue outlining:
* What the feature is
* Why it would be useful
* Any potential implementation ideas you have

### Pull Requests
We welcome pull requests for bug fixes, new features, and improvements!
1. Fork the repository and create your branch from `main`.
2. Ensure you have installed the required dependencies for the frontend and backend.
3. Make your changes and test them locally.
4. If you've changed APIs, make sure they are documented.
5. Create a Pull Request with a clear description of what you changed and why.

## Development Setup

See the [README.md](README.md) for detailed setup instructions. 
At a high level, this project uses:
* **Frontend**: React + Vite
* **Backend**: NestJS
* **AI Tooling**: Python + Antigravity SDK

## Known Areas for Improvement
* **PDF Formatting**: Some generated PDF questions and options are not yet fully formatted or aligned nicely. Improvements to the PDF layout are highly welcomed!
* **AI Agent Workflows**: Enhancing the `generate_exam_agent.py` to support more complex prompt customization.

Thank you for your interest in making this project better!
