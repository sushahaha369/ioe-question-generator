# Specification: NestJS IOE Entrance Exam Question Paper & Answer Key Generator

This specification outlines the updated requirements, including separate Answer Key generation and AI error disclaimers.

---

## 🎯 1. Objective
Build an **IOE Entrance Exam Question Paper & Answer Key Generator** that:
- Generates a print-ready **Question Paper PDF** (exactly 100 questions, no answers).
- Generates a separate **Answer Key PDF** containing correct options and detailed explanations ("Why").
- Includes an AI error disclaimer ("Generated by AI. AI can make errors.") on the website, PDF footers, and preview.
- Simplifies the UI to focus on interactive practicing and easy downloads, removing browser-printing controls and embedded PDF frames.

---

## 📐 2. Exam Rules & Disclaimers
- **Standard Layout**: 100 MCQs, 100 Marks (1 mark each), 2 hours duration, and 5% negative marking.
- **AI Disclaimer**: All generated documents and interfaces must include:
  `"Disclaimer: This question paper and answer key are generated by AI. AI can make errors. Please verify calculations and concepts."`

---

## 🛠️ 3. Tech Stack
- **Backend**: NestJS, `pdfkit`, `cheerio`
- **Frontend**: React, Vite, Vanilla CSS (macOS app design)

---

## 📂 4. Project Structure
- `backend/` - NestJS application.
- `frontend/` - React application.

---

## 🏆 5. Success Criteria
1. The frontend features two distinct download actions: "Download Question Paper" and "Download Answer Key".
2. The print button, PDF preview iframe, and tab bar are removed from the browser UI.
3. The PDF footers and the web preview display the AI error disclaimer.
4. The generated Answer Key PDF contains correct options and "Why" explanations for each question.
